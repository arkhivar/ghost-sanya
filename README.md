# Хайнань — личный атлас

Русскоязычная тема Ghost: интерактивная карта Хайнаня, история семейной поездки, сравнение бухт и подборка жилья.

## Разработка

Нужны Node.js и pnpm указанной в `package.json` версии. Сам Ghost устанавливается отдельно.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm test:ci
pnpm zip
```

Сборка хранится в `assets/built/`. Команда `pnpm zip` создаёт архив темы для загрузки в Ghost. Проверки GitHub Actions запускаются при push; автоматическая публикация сайта не настроена.

## Что сохраняет этот репозиторий

Исходники темы, собранные CSS/JS, шрифты, изображения и документацию. Записи Ghost, настройки сайта, база данных и учётные данные хранятся отдельно. Для их восстановления нужен отдельный экспорт Ghost и копия загруженных медиа.

После каждого локального коммита выполняется push в `arkhivar/ghost-sanya`.
